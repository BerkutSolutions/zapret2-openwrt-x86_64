# Zapret2 для OpenWrt x86_64

Пакеты и LuCI-интерфейс Zapret2 для роутеров на OpenWrt `x86_64`.
Проект основан на [Zapret2 от bol-van](https://github.com/bol-van/zapret2).

Это неофициальная сборка для OpenWrt x86_64. Для работы используются штатные
пакетные менеджеры OpenWrt и веб-интерфейс LuCI.

## Установка

Установить последний опубликованный релиз можно одной командой:

```sh
sh <(wget -O - https://raw.githubusercontent.com/BerkutSolutions/zapret2-openwrt-x86_64/main/Zapret-Manager.sh)
```

Установщик проверяет архитектуру устройства, загружает подходящие пакеты и
проверяет их контрольные суммы перед установкой.

Для ручной установки скачайте из раздела Releases пакет Zapret2, пакет UCI,
пакет LuCI и файл `SHA256SUMS`. Перед установкой проверьте контрольные суммы.

## Что входит

- движок и служебные компоненты Zapret2;
- конфигурация и интеграция с UCI OpenWrt;
- веб-интерфейс LuCI;
- установщик `Zapret-Manager.sh`;
- исходный код соответствующей сборки.

## Лицензии и благодарности

Исходный код Zapret2 распространяется по лицензии MIT автора bol-van.
Собственная OpenWrt-упаковка распространяется по Apache-2.0.

Часть LuCI/backend-интеграции предоставлена Routerich. Ссылка на
проект: <https://github.com/routerich>.

Подробные уведомления и лицензии компонентов находятся в файлах `LICENSE`,
`NOTICE` и `THIRD_PARTY_NOTICES.md`.

## Сборка

Исходники пакетов и LuCI рассчитаны на сборку для OpenWrt `x86_64`. Для
пользовательской установки рекомендуется использовать готовые релизы.
